# MyGO X 引擎 v1.1 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 v1 單帳號唯讀引擎上擴充五域——多帳號（模型 A＋墓碑）、媒體（縮圖＋展開播放）、雙時間線、搜尋、頂列響應式 UI——全程 RAM 峰值 <80 MiB。

**Architecture:** 引擎層（`internal/xapi`）僅增不改：`Sender` 新增 `HomeLatestTimeline`/`SearchTimeline` 兩操作與 `Post.Media` 資料面。app 層新增 `accounts.go`（帳號儲存＋遷移）、`media.go`（縮圖 LRU）、`view_detail.go`/`view_search.go`；改造 `session.go`（`newSessionFor`＋`Close`）與 `main.go`（`switchTo`＋世代邊界＋憑證預熱）。單活躍會話、per-session context 子樹、世代號 publish 過濾。

**Tech Stack:** Go 1.27.3、MyGO v0.9.0（ui/ui/video）、bogdanfinn/tls-client v1.18.0（chrome_150）、MyGO Secrets（憑證庫）。

**Spec:** `docs/designs/x-engine-v1.1.md`（§8 為實作契約）＋`docs/designs/concepts_brief_v1.1.md`（D11–D22 依據）。本計畫與規格矛盾時以設計文件為準。

**前置條件（需求方）：** Task 2 需一枚**有效的新 cookie**（貼入環境變數，不進檔案與對話記錄）。

## Global Constraints

- Go 1.27.3；module `github.com/OG-Open-Source/RIGG/X`；`internal/xapi` **不得 import MyGO**（`X/importban_test.go` 釘住，動到即失敗）。
- 零 cgo；MyGO 釘 v0.9.0；TLS 棧僅 tls-client chrome_150（不得引入第二套）。
- 引擎公開 API **僅增不改**：`Sender.Send/HomeTimeline/Viewer` 簽名不動；`Post` 僅增欄位。
- RAM 行程峰值 **<80 MiB**；帳號上限 **5**；seen 上限 **500**（截尾保留最近）；縮圖併發 **≤4**；縮圖 LRU **≤24 MiB**（解碼位元組）。
- 憑證材料只進 MyGO Secrets；錯誤字串與日誌絕不含 cookie 值（REQ-INV-01）；探測輸出脫敏。
- 每帳號 secret ≤ **MaxSecretSize 2560**（超限回錯誤並提示精簡，不靜默截斷）。
- 每帳號一 secret 鍵：`x-account-<user_id>`；索引 `x-accounts`；舊鍵 `x-cookie-line` 降級雙寫期保留（v1.2 清理）。
- 測試 fixture 一律合成（**不得**複製 X 回應原文——clean-room）；`go vet ./...` 與 `go test -race -count=1 ./...` 全綠為每任務退出條件。
- web 測試載體：每任務 commit 前 `go tool mygo build -platform web` 編譯冒煙通過（web 不驗資料面）。
- Conventional Commits；一域一 commit；訊息繁中或英文皆可但型別字首必須正確（feat/fix/test/docs/chore）。
- 工作目錄：一律於 `C:\Users\User\Documents\GitHub\RIGG\X` 下執行 go 指令（repo 根無 go.mod）。

## Review Focus

計畫未由任務測試覆蓋、最可能咬到使用者的五類輸入（每行已釘測試於所屬任務）：

1. **世代過期的 publish**——切換帳號後，舊帳號的 in-flight Home 回應不得寫入新畫面（尤其 `seen` 不得混入他帳 work_id）。→ Task 6 `TestSwitchGenerationDiscardsStalePublish`。
2. **write-through 寫錯帳號**——ct0 輪替必須落活躍帳號的鍵，不得覆蓋他帳。→ Task 5 `TestWriteThroughTargetsAccountKey`。
3. **切換失敗的收斂**——Viewer 驗證失敗時：原會話不動、索引回寫原帳號、目標帳號標記失效且 secret 保留。→ Task 6 `TestSwitchFailureRollback`。
4. **seen 無界成長**——長翻頁後 `seenTweetIds` 不得超過 500 且 POST 仍有效（截尾保留最近）。→ Task 8 `TestSeenCapTrimsTail`。
5. **媒體 format 參數**——PNG 來源誤用 `format=jpg` 會 404（實證）；萃取必須沿用 `media_url_https` 的副檔名。→ Task 11 `TestMediaExtractionPreservesFormat`。
